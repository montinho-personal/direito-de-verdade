O primeiro parágrafo é o lead: aparece em destaque logo abaixo do título. Ele precisa
responder direto a dúvida principal, em 2 ou 3 frases. Quem chegou pelo Google quer a
resposta logo no começo.

## Use "##" para as seções principais, no formato das perguntas reais

Cada seção com "##" entra no sumário "Neste artigo" (que aparece quando há 3 seções ou
mais, contando as perguntas frequentes).

### Use "###" para subtítulos dentro de uma seção

Texto normal em parágrafos curtos. Use **negrito** para o que é mais importante.

- Listas com hífen
- Para itens soltos

1. Listas numeradas
2. Para passo a passo

> **Atenção:** linhas começando com ">" viram um quadro de destaque.

| Situação | O que acontece |
| --- | --- |
| Tabelas também funcionam | Bom para comparar casos |

Links internos vão no meio da frase, com o texto que descreve o destino:
[como funciona o aviso prévio](/artigos/aviso-previo). Para citar a lei, link para a fonte
oficial: [Consolidação das Leis do Trabalho (CLT)](https://www.planalto.gov.br/ccivil_03/decreto-lei/del5452.htm).
