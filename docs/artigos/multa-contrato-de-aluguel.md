## Pendente

- Valor "comum" de multa (3 aluguéis): é prática de mercado, sem fonte oficial; o
  texto usa 3 aluguéis só como exemplo de conta e manda ler o contrato.
- Reajuste do aluguel (IGP-M/IPCA) e despejo: ficam para artigos próprios da pauta.

## Decisões

- Título "Multa de contrato de aluguel: cálculo e quando não paga" (55): provisório
  até os prints.
- A fórmula proporcional é apresentada como a forma mais simples, com a ressalva do
  STJ (equidade) para não prometer valor exato.
- Sem link forçado para artigos de consumidor: locação não é relação de consumo;
  o único link interno é para a seção do Juizado.
